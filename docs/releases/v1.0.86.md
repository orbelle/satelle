## [1.0.86] - 2026-11-18

### Changed
- Each delivery story is rated low or high risk by a cold risk-assess gate on plan -> in_progress (recorded as its risk tag), and code-ac dispatches the panel satelle.toml [review] names for that tier: one judge for low, two for high. (sto_e00a3845)
- This repo's gpt reviewer runs gpt-5.6-sol-medium (binding reviewer-gpt-5.6-sol-medium) instead of gpt-5.6-sol-high (sto_ae119938). (sto_ae119938)
- Every judged gate in this repo's workflows names its reviewers as a panel (`panel = [...]`, `combine = "all"`), one judge or several; pr-review still publishes under its reviewer's binding (sto_f9f90635). (sto_f9f90635)
- An item's changed paths (`satelle <kind> diff`, a gate's `paths` match and a judge's `Changed paths:`) are its commits since its base and its uncommitted changes to tracked files. Untracked files in the worktree are listed apart, marked untracked (`untracked: <path>` in `diff`, `untracked` in `diff --json`, their own block in a judge's prompt), and are no longer attributed to the item. A new file counts as a changed path once it is added (`git add`). (sto_ac3d04af)

### Fixed
- An item with no recorded base (for example one created through the satelle MCP) can be cancelled or moved to any judged terminal state: its change is read as empty instead of running `git diff` with an empty revision (sto_f98743d0)
- A judge's verdict whose notes hold an invalid JSON escape (such as \. in a quoted regex or a Windows path) is read as the judge gave it instead of being recorded as a reject (sto_500b0c94)

## [1.0.172] - 2026-11-28

### Changed
- a story targeting a repository registered in .satelle/repos.toml now has its base, changed paths, diff, stale-base check, collected branch and frozen terminal diff read from that repository's checkout (mapped at its top level in .satelle/repos.local.toml, at a path of only A-Z a-z 0-9 . _ / + @ -, a complete clone rather than a partial one, of sha1 or sha256 object format, read with git 2.44 or later, and the same checkout the story was seated at), with the checkout's own origin, no GIT_* or credential variables, no lazy fetch or credential prompt, no fsmonitor, credential helper, textconv, external diff, filter or attribute from its config or files, and no look inside a submodule's work tree (a submodule's commit change still shows); its gates still run in the control repository, with the reviewer's prompt carrying the target's diff and a Target work tree line and check gates getting SATELLE_WORKTREE (and worktree on stdin), which satelle no longer passes through from its own environment; a target whose checkout is unmapped, missing, below its top level, at an unsafe path, a partial clone, has another origin, is read by a git older than 2.44 or moved since the seat is refused a seat or a gated move, and a remote-placed gate on such a story is rejected with a note to place it locally; self and single-repo stories read the control repository as before (sto_57932ef8)

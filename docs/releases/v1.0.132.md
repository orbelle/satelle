## [1.0.132] - 2026-11-23

### Added
- `satelle remote fire --detach` returns once a docker-local node has its work, and `satelle remote status` brings the run back: it imports the node's chains verified, records the verdict, releases the node's seat and removes a run-scoped container, or records the run stopped when the node failed or its container is gone. (sto_e74a71e5)
- `satelle remote status` on a detached docker-local run says whether the node still answers: running with the step the node last started, or lost with the time it last answered, recording nothing. (sto_f53b7de1)
- `satelle remote stop <remote> <item>` ends a detached docker-local run's node: it removes the container, records the run stopped with who stopped it and releases the node's seat (sto_1949022f)

### Fixed
- A docker-local node's files are copied back through the same unpacker as a command node's, which refuses a link or a path outside the copied file. (sto_e74a71e5)

## [1.0.142] - 2026-11-25

### Added
- Every ledger event satelle appends carries `origin` in its payload: the machine id, the worker role that wrote it (session, performer, judge, sync or node), the harness when one is detected, and the worktree; satelle sets it and replaces any caller-supplied origin, the hash and envelope are unchanged, and queue-file mirror events carry none. The origin is provenance for tracing faults, not an authorisation fact. (sto_7fbfa65c)

### Changed
- `satelle ledger append --payload` accepts only a JSON object, and refuses a payload that names `origin`. (sto_7fbfa65c)

### Fixed
- A queue file is mirrored onto its chain only from the repository's main checkout; a command in a linked git worktree no longer appends the file's definition to the shared chain, so worktrees with an older or newer queue file cannot flip it. (sto_fbda22c6)
- A queue whose only local events past a fork are its file's mirror events now takes the store's chain on ledger pull and the sync pass, and mirrors the file onto it, instead of being refused. (sto_7a47551c)

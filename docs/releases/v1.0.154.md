## [1.0.154] - 2026-11-27

### Fixed
- A remote node whose run left its substrate unchanged imports its run again: the unchanged-substrate check no longer compares a directory's inode number, which overlayfs changes when a directory is evicted from the inode cache; a directory's mode, device, ctime and link count are still compared, and a changed file is still named by its own path.

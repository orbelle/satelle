## [1.0.166] - 2026-11-28

### Added
- `satelle capacity` also reports each other machine the repo reaches through a command remote whose `[connect] exec` names no `{node}`, asking it with `satelle capacity --json --here`, and names a machine that does not answer as unreachable without failing the rest; `--here` reports this machine only and `--json` prints the reports as JSON (sto_3e38ecb2)
- `satelle status` shows the control directory and target (self for a repository with no repos.toml), and in a checkout that a control repository maps in .satelle/repos.local.toml, or a linked worktree of it, status, session context and doctor read that control repository read-only, while every other command there still does not resolve. (sto_df2091c3)

### Fixed
- Moving an item into a terminal state of its workflow (done, cancelled, or any state its workflow marks terminal) now releases every seat bound to it, whatever session or location holds it, as part of the move: no session or operator releases one by hand any more, and `satelle doctor --resolve` still releases a seat a failed release or an earlier version left behind. (sto_f41d1131)
- A binary replaced at the same path with the same size and modification time is now probed again instead of reporting its old recorded version, and TestIdentifyProbesOnceThenReads no longer fails intermittently. (sto_7fedb313)

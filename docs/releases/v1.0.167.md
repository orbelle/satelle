## [1.0.167] - 2026-11-28

### Added
- A queue file's `[filter]` takes `repo = "<name>"` (`self` for the control repository): the queue's members, its enqueues and `satelle queue fire` keep only items targeting that repository, an add of an item targeting another repository is reported and not queued, and `satelle validate` names a repo that `.satelle/repos.toml` does not register.

## [1.0.81] - 2026-11-17

### Added
- satelled shows a chip for the current step of an item that has never moved (a backlog story, an open drift fix item), instead of a dash (sto_99a915dc)
- satelled's 'N engaged' and 'N elsewhere' header counts list the stories engaged here or elsewhere when clicked, and the filter box takes engaged:here and engaged:elsewhere (sto_18f1e94d)

### Changed
- satelled's progress chips name parks by the workflow's own park state (e.g. blocked 1, 'blocked once while at this step'), each park state counted apart, never the word park (sto_99a915dc)
- satelled's tag filter follows parent links: clicking an epic's tag shows the epic and every story under it, including children that do not carry the tag (sto_dbff7bc7)
- satelled's Projects page lists this machine's projects (`[projects] paths`), one row per entry with its partition's counts once it has pushed; a partition of a repo that is not an added project is no longer listed (sto_d2d7cc2b)
- A repo under the temp dir (the system temp dir and `/tmp`) pushes nothing to satelled, added or not (sto_d2d7cc2b)
- `satelle project partitions` marks each partition `added` or `not-added`, and `satelle project prune <repo_key>` drops a `not-added` partition without `--force` (sto_d2d7cc2b)

### Fixed
- satelled's stories table scrolls sideways inside its own box at narrow widths instead of overflowing the page (sto_07b505bb)

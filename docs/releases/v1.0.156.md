## [1.0.156] - 2026-11-27

### Changed
- The edit gate refuses a git push whose destination is the branch of an item the session holds no seat on in a state whose performer may change the tree, naming that item; pushes to main and other branches that are not an item's id are allowed as before. (sto_da6dddb9)
- A push is judged by the literal branch destination written on a line the gate reads; a push with no refspec, HEAD alone, a pattern refspec, a non-branch refs/ destination, --all, --mirror or --tags, or an unlisted git option before push is refused with the written form. A line naming git that the gate cannot read is refused under the existing fail-closed rule. (sto_da6dddb9)

## [1.0.124] - 2026-11-22

### Added
- The herdr stories panel shows the installed satelle version in a footer, read from `satelle version` on each refresh, and says it is unknown when satelle cannot answer (sto_0e57a3ba)
- The herdr stories panel shows a "clear all" button beside the filter while it holds text; one click empties the filter of the space shown and keeps the selected chip, as satelled's Stories filter does. (sto_48a6cdd2)
- The herdr stories panel shows each step's rejected rounds as a red (n) on its step chip, as satelled does. (sto_1e33fd46)
- A docker-local remote's `[secrets] names` are now handed to its node: `satelle remote fire` reads each from the firing shell's environment, drops it from its own environment before starting any git or docker command, and gives it to the node process over its stdin, never in argv, the container's configuration, the ledger or on disk; the node runs `[setup]` after it is given its secrets and replaces each value in its check, judge and agent output before any of it is cut or recorded; an unset name, or a secret beside a `[network] allow` entry, refuses the fire before a container starts, and a node record carrying a declared value is not imported. (sto_9fac95cd)
- The `docker-secret-probe` remote, its `secret-probe` workflow and `satelle-probe-secret-check` skill prove the path on one container: the step records only the sha256 of the value it and `[setup]` read. (sto_9fac95cd)

### Changed
- The herdr stories panel keeps each space's own filter: the selected chip (active, backlog, done or all) and the filter box text are stored per herdr space id in the panel's persisted localStorage, so switching spaces shows each repo as it was last left and a new space starts at active with an empty filter (sto_016c72cb)
- A docker-local task drive refuses, at its fork, a chain that also changed here while the node ran: the run's record names it with both heads, the run's other chains are imported, and the run concludes reject; the secret scan covers a forked chain's events past the shared history. (sto_ce735ff1)

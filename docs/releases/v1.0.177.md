## [1.0.177] - 2026-11-28

### Added
- A registered repository's part may bind its own agents in .satelle/repos/X/agents.toml: X's workflows dispatch a performer, judge or fallback bound there, and the shared .satelle/agents.toml binding otherwise; a part agents.toml that does not load, names an agent outside lower-case letters, digits, '.', '_' and '-', or binds an agent or fallback on a harness no non-session binding of the shared agents.toml runs, leaves the part unresolved; the judge-differs check compares a part's workflows, by the directory their file is in, against the part's bindings, and fails when .satelle/workflows, .satelle/repos, a part directory or its workflows directory is a symbolic link, or when .satelle/workflows resolves under .satelle/repos; with no part agents.toml every agent resolves from the shared file as before.

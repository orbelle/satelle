## [1.0.131] - 2026-11-23

### Changed
- A remote definition that declares [secrets] with [lifecycle] scope = "job" is refused by `satelle validate` and by `satelle remote fire`. (sto_6c982cc4)

### Fixed
- A remote node's concluded status is the last status it posts: a heartbeat call in flight when the run ends now finishes before the conclusion is sent, so a concluded node is never left shown as running. (sto_9d8e8bf4)

### Security
- A docker-local node whose definition declares [secrets] is removed, with its egress container and network, when its run fails, is cancelled or times out, not only when it concludes; an interrupted `satelle remote fire` now cancels the run and removes it too. (sto_6c982cc4)

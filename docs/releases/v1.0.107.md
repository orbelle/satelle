## [1.0.107] - 2026-11-21

### Changed
- This repo's doctor judges open drift with the check skill satelle-drift-ownership-check: a drift-key an open story owns (tag drift-owns:<drift-key>) is a note naming that story, and only unowned keys are an issue (sto_1f9dade4)
- An unknown key in an advisory .satelle file (doctor.toml, ui.toml, init.toml, volatile.toml, harness.toml) or in satelle.toml's hook, items, service, sync or ledger table no longer stops satelle from loading the repo: satelle validate lists it and still reports the configuration valid, and satelle doctor and the session-start doctor block report each with its file, table and value. Files and tables that define gates and permissions (workflows, queues, agents.toml, agents.local.toml, satelle.toml's workflows, gate and review tables, and any unknown satelle.toml table) still refuse an unknown key (sto_9fdace64)

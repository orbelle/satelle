## [1.0.168] - 2026-11-28

### Changed
- `satelle github review` and `satelle github status` send the item they publish for as `item_id`, from `--item` or else `SATELLE_ITEM`, so satelle.dev can resolve the item's repository; with neither set they refuse, and neither command takes a repository (sto_d9427fec)
- GitHubService PublishReview and PublishStatus carry `item_id`, and a request without one is refused with INVALID_ARGUMENT (sto_d9427fec)

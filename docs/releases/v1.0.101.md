## [1.0.101] - 2026-11-20

### Added
- The sync timer now makes satelle doctor's no-answer fixes in every project on its own: it releases a seat whose session has ended on this machine or whose item is in a terminal state, once the item is in sync with the ledger store, and restarts a satelled running another build than the installed one. `satelle logs --doctor` lists each fix (sto_b71dc93a)

### Changed
- Session start lists a seat-release or build-skew restart issue, in the user's notice and the model's context, only when the sync timer's last pass left it; with no recent pass it lists them all as before. `satelle doctor` still lists every issue (sto_b71dc93a)

## [1.0.96] - 2026-11-19

### Added
- `satelle help workflows` names the JSON object a check skill gets on stdin: `id`, `from`, `to` and `base`, each beside its `SATELLE_ITEM`, `SATELLE_FROM`, `SATELLE_TO` or `SATELLE_BASE` variable (sto_4e11a754)
- satelle status says when this repo is bound to a satelle.dev project but is not one of this machine's projects, and names satelle project add (sto_56094951)
- `satelle <kind> diff <id> --stat` prints each changed path with its added and removed line counts (`binary` for a binary file) and a total line, over the same base as the plain diff and, for an item in a terminal state, over its frozen change; `--stat --json` adds `stat` and `total`. Untracked files stay listed as `untracked: <path>` and are not counted. (sto_40988132)
- satelle validate lists each skill that no workflow, doctor check or [hook] inject entry names and no such skill reaches (skill_warnings with --json), without failing the check (sto_b9ca62cf)

### Changed
- A README.md in .satelle/skills is no longer loaded as a skill (sto_b9ca62cf)

### Removed
- internal/syncstate's command-policy cache (policy.go) and the RecordSubstrate and MarkSubstrateAttempt records, which no binary used (sto_a0f868db)
- Five skills nothing ran (land, satelle-lessons, satelle-design-review, satelle-integration-review, satelle-story-release-review) and the frontmatter keys v1 does not read (sto_b9ca62cf)

### Fixed
- `satelle hook context` and `satelle hook prompt` print the `satelle session:` line when the repo's configuration is invalid, so a session knows its id and can seat once the configuration is repaired. (sto_7e839979)
- satelle agents install and satelle init --hooks say when a gitignore rule hides the harness file they wrote: the output names the file, the rule as git check-ignore -v reports it, and the git add -f command that commits it (sto_43507f3e)
- A record folder left in .satelle/runs by a run that was killed before its cleanup is removed when the next performer or judge run writes its folder; a folder whose run is still in progress is kept. (sto_403183dc)

### Breaking
- A global config (~/.satelle/config.toml) that still has the pre-1.0 [workspace] table is refused, naming the file and the [projects] paths form to use; it is no longer migrated silently (sto_c1a56864)

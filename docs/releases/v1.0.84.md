## [1.0.84] - 2026-11-17

### Added
- satelle init --print <path> prints one file this release ships and writes nothing. (sto_06c11721)
- .satelle/init.toml: category names the category the printed story command carries (a new repo ships with it; a repo that names none and lacks a shipped file gets no command and a doctor finding naming the key and the categories its workflow rules select); removed records shipped files a repo removed on purpose, which satelle init and satelle doctor then do not report. It is its own file, so an older satelle still opens a repo that has it. (sto_06c11721)

### Changed
- satelle init in a repo that already has .satelle/satelle.toml writes nothing under .satelle/: it lists the files this release ships that the repo lacks and prints the satelle story create command that raises a story for them, which is the user's decision. That story's session writes each file from satelle init --print <path>. (sto_06c11721)
- satelle doctor --resolve opens no item for a missing shipped file: doctor and --resolve list each with the command that raises the story. (sto_06c11721)

- `satelle doctor` notes each skill, task or remote `[setup]` line whose shell text reads a `.satelle/` path relative to the working directory, with its file, line and the `$SATELLE_SUBSTRATE_DIR` form to use, and changes nothing (sto_3b97ad87)

(sto_fc858c43)

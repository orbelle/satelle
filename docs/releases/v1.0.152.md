## [1.0.152] - 2026-11-27

### Changed
- A docker-local or command node unpacks the firing tree's substrate read-only at /node/substrate, apart from its work tree /node/work (the checked-out commit with [drive] checkout = true, whose own .satelle stays unchanged there), and a satelle command a check runs inside the node opens /node/substrate; the node checks the substrate after every setup command, before every check and dispatch, and at the end, and a run whose setup or steps change, add or remove anything under it, even when restored, is rejected naming each path, and nothing of it is brought back. A commit that tracks a symlink at .satelle, or anything at .satelle/runs, is refused, and so is a run whose work tree has been replaced by a symlink before a record folder is written. This is node layout 3: a firing satelle and a node of another layout are refused before setup. (sto_89ea4447)

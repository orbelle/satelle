## [1.0.163] - 2026-11-27

### Added
- satelle repo add and satelle repo list register onboarded target repositories in tracked .satelle/repos.toml (origin, base, fetch, tier) and map their checkouts in git-ignored .satelle/repos.local.toml; repo add needs a tree seat and honours [gate] locked_paths, a credentialed origin is refused and every origin is shown without credentials, query or fragment; satelle doctor reports unmapped or missing checkouts, origin mismatches, a checkout onboarded by two control repositories and a doctor.toml [repos] max_count overrun, and satelle validate refuses an unknown tier (sto_24387c93)

### Fixed
- `satelle update` and `satelle service refresh` no longer restart satelled or satelle-follow.service when both binaries are current, the units match what satelle would write and each runs the installed binary; a replaced binary or a rewritten, missing or repointed unit restarts as before, and `satelle service restart` still restarts unconditionally. (sto_bb6a56e8)
- gitfacts check-ignore, merge-base and symbolic-ref queries now run with the credential-stripped git environment their caller supplies, and displayed paths quote Unicode format characters as well as control characters (sto_24387c93)

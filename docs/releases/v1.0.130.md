## [1.0.130] - 2026-11-23

### Added
- A remote whose `provider = "command"` is fired from this machine: satelle runs the start, copy_in, exec and stop argv lists its `[connect]` table names (`{node}`, `{src}` and `{dst}` substituted, never through a shell), copies itself in, runs the node contract over exec with secrets only on stdin, and runs stop when the run ends with `scope = "run"`; an optional `[connect] check` refuses the fire before start, and a `[network] allow` list on a command remote is refused until it is enforced. (sto_6f443768)
- `satelle validate` reports every remote definition's (`remotes/<id>/remote.toml`) schema errors as problems. (sto_6f443768)
- A command remote's `[network] allow` is applied by the `[connect] network` command after start and read back before any work: a node that reports a different list is refused and stopped, and a command definition without `[connect] network` is refused. (sto_865a38eb)

## [1.0.170] - 2026-11-28

### Added
- `satelle capacity` shows this machine's worker ceiling beside the live agent count, from `[capacity] workers` in ~/.satelle/config.toml (`satelle settings set capacity.workers N`); with none set it shows no ceiling. (sto_f8e595da)

### Changed
- satelle capacity reuses its machine sample for 30 seconds: the cores, memory, load and process figures are kept in the satelle home as capacity-sample.json, readable by your user only and shared by every project on the machine, while engaged seats are still read on every run (sto_55574f85)

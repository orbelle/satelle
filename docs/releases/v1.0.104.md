## [1.0.104] - 2026-11-20

### Added
- Each judged `gate.run` now records the judge's configured `effort` (when set by its binding, omitted when unset) and `prompt_bytes` (the byte length of the prompt given to the judge), on the top-level payload for a single judge and on each `members[]` entry for a panel (sto_8a02f0b2)
- satelle gate report --item <id> [--json] prints one item's outcome: each performed state with its command and model, each judged gate's rounds with the judge's model and verdict, and whether the item reached a terminal state; a run recorded without a model shows unknown, never read from agents.toml (sto_b70d4e06)
- satelle agents auto-mode claude prints Claude Code's autoMode block ("$defaults" followed by each non-empty line of .satelle/auto-mode.md) and names ~/.claude/settings.json as where it belongs, writing no file; satelle init ships .satelle/auto-mode.md, and other harnesses are reported as unavailable (sto_3f621342)
- A judge binding in .satelle/agents.toml can carry an optional brief; a gate's dispatched judge then gets the brief in its prompt, and a binding with no brief gets the same prompt as before (sto_16152e29)

## [1.0.149] - 2026-11-27

### Changed
- A satelle command started by a node run's task or check opens that node's own substrate and ledger, found through the node's runtime stamp and its process ancestry rather than by walking up from the work tree. A runtime that is the machine's is never opened that way, a refused node hint fails the command (satelle doctor included) instead of reading as not in a repo, the hooks, ledger autosync and the session-start doctor never take this path and keep their exit codes, a node run is checked before its ledger is pushed or its outcome written, a local run's ledger is imported only when the node signed its outcome with an Ed25519 key handed to it on stdin, the starter keeping only the public key (node layout 2), the substrate digest is enforced where the substrate is separate from the work tree, and declared secrets are withheld from every git command resolution runs, gate jobs included (sto_35ca4a0b)

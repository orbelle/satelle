## [1.0.123] - 2026-11-22

### Added
- A docker-local remote runs a task drive: satelle remote fire <remote> <task> runs the task once in a container and brings back every chain the run wrote, each verified before any is imported; a chain that does not verify imports nothing and concludes the run reject. The repo's docker-task-probe remote fires the probe task (.satelle/tasks/docker-task-probe.md). (sto_873d267d)
- `satelle herdr install` installs satelle's stories panel and `satelle` layout into herdr-app's home (`~/.config/herdr-app`, `HERDR_APP_HOME`, or the machine setting `herdr.home`), and `satelle update` refreshes it where it was installed (sto_ab933beb)

### Changed
- Each binary-changed release writes its notes to docs/releases/v<version>.md instead of prepending a section to CHANGELOG.md, which stays as the archive of earlier versions; the changelog-entry gate reads that file (and CHANGELOG.md for older versions), and an item editing docs/releases is refused as an edit to CHANGELOG.md is (sto_15e01e89)
- Track this repository's `.agents/hooks.json`, budget `[agy]` in `.satelle/harness.toml`, and reset `tests/testdata/repo_findings.golden` to clean validate/doctor findings. (sto_88f9db5f)
- Each delivery and chore story is rated low or high risk by a risk-assess gate that records its risk tag, and the security and code-ac judges are picked by that tag; a story with no rating is judged by the high tier. (sto_65961809)

### Fixed
- The satelle node image installs jq, so a check skill that reads the ledger with jq runs on a docker-local node instead of failing with "jq: not found". (sto_7ac1341c)
- The docker-local round-trip test asserts that an accepted docker-probe run removes its container, as the probe's lifecycle now declares. (sto_63291d86)

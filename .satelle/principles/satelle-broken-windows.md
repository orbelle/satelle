# Broken windows

A failure you meet is yours. Fix it if it is cheap or in your change's path;
otherwise file a story that names it and tell the operator. Never pass one by
silently.

Never add a new red: a change that leaves a failing test, a skipped or disabled
check, or unowned debt is not done. Known debt only shrinks, and each piece is
owned by a story. "It was already broken" is not a pass once you build on it.
